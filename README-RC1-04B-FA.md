# Carrtell RC1-04B — سرویس در محل بدون نیاز به API نشان

این نسخه جایگزین RC1-04 قبلی است و در زمان توسعه به کلید نشان نیاز ندارد.

## وضعیت فعلی
- نقشه رایگان OpenStreetMap نمایش داده می‌شود.
- انتخاب نقطه با کلیک یا جابه‌جایی نشانگر فعال است.
- دریافت موقعیت فعلی مرورگر فعال است.
- نوشتن آدرس دستی کافی است و انتخاب نقشه اجباری نیست.
- مختصات فقط وقتی کاربر موقعیت را انتخاب کند ذخیره می‌شود.
- جست‌وجوی متنی و تبدیل خودکار مختصات به آدرس تا زمان اتصال نشان غیرفعال است.

## نصب
1. محتویات ZIP را داخل پوشه project کپی و Replace کنید.
2. فایل SQL زیر را یک‌بار در Supabase SQL Editor اجرا کنید:
   supabase/migrations/202607230009_rc1_04_onsite_service_complete.sql
3. سرور را مجدداً اجرا کنید و مرورگر را Hard Refresh کنید.

## اتصال نشان در آینده
بعداً فقط این متغیرها را در `.env.local` قرار دهید:
VITE_NESHAN_MAP_KEY=...
VITE_NESHAN_SERVICE_KEY=...
