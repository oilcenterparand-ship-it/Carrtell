# RC1-03C — تعمیر راه‌اندازی Super Admin

این پچ مخصوص حالتی است که حساب ورود در Supabase Auth از قبل ساخته شده، اما رکورد مدیریتی آن در `admin_accounts` وجود ندارد و ورود پیام «این حساب اجازه ورود به پنل مدیریت را ندارد» نشان می‌دهد.

## نصب

1. فایل‌های پچ را داخل ریشه پروژه کپی و Replace کنید.
2. فقط فایل زیر را در Supabase SQL Editor اجرا کنید:

`supabase/migrations/202607230005_rc1_03c_admin_setup_repair.sql`

3. برنامه را اجرا کنید و به آدرس زیر بروید:

`http://localhost:5173/admin/setup`

4. همان نام کاربری قبلی را وارد کنید و یک رمز جدید تعیین کنید. اگر کاربر Auth از قبل وجود داشته باشد، Carrtell همان حساب را به Super Admin تبدیل می‌کند و رمز را نیز به مقدار جدید تغییر می‌دهد.

## نکته امنیتی

صفحه Setup پس از ایجاد اولین رکورد مدیریتی به‌صورت دائمی بسته می‌شود. هیچ کلید Service Role در مرورگر قرار نمی‌گیرد و برای این مرحله به CLI یا Edge Function نیاز نیست.
