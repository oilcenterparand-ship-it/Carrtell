# README فارسی — Carrtell OTP UX V2

## مبنا
این پچ مستقیماً بر اساس سورس واقعی `project(4).zip` ساخته شده است.

## هدف
بهبود کامل تجربه ورود/تأیید شماره موبایل در صفحه `/login-otp` بدون تغییر در Secretها، SQL یا تنظیمات Kavenegar/Supabase.

## تغییرات
- ورودی OTP به ۶ خانه مجزا تبدیل شد.
- حرکت خودکار فوکوس بین خانه‌ها اضافه شد.
- Backspace صحیح بین خانه‌ها پیاده‌سازی شد.
- Paste کردن یک کد ۶ رقمی کامل پشتیبانی می‌شود.
- روی موبایل کیبورد عددی باز می‌شود.
- پشتیبانی از `one-time-code` برای پیشنهاد خودکار کد پیامک در مرورگر/موبایل اضافه شد.
- تایمر ۲ دقیقه‌ای برای ارسال مجدد اضافه شد.
- دکمه «ارسال مجدد کد» تا پایان تایمر غیرفعال است و پس از پایان فعال می‌شود.
- پس از ارسال مجدد، تایمر و خانه‌های کد ریست می‌شوند.
- شماره موبایل در صفحه تأیید به فرم محلی `09...` نمایش داده می‌شود.
- دکمه تأیید تا وارد شدن کامل ۶ رقم غیرفعال است.
- خطاهای فنی Supabase/Kavenegar به پیام‌های فارسی مناسب کاربر تبدیل می‌شوند.
- مسیر `returnTo` و منطق بازگشت به سبد خرید/صفحه قبلی حفظ شده است.

## نصب
1. از پروژه فعلی Backup بگیر.
2. محتوای پوشه `project` داخل ZIP را روی ریشه پروژه خودت کپی کن.
3. در صورت سؤال ویندوز، گزینه Replace را بزن.
4. سپس اجرا کن:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
npm run typecheck
npm run build
```

5. محتوای پوشه `dist` جدید را روی `public_html` هاست جایگزین کن.

## تست روی سایت
1. صفحه ورود با موبایل را باز کن.
2. شماره معتبر `09...` وارد کن و کد بگیر.
3. بررسی کن ۶ خانه مجزا نمایش داده شود.
4. با وارد کردن هر رقم، فوکوس باید به خانه بعد برود.
5. Backspace باید به خانه قبلی برگردد.
6. یک کد ۶ رقمی را Paste کن؛ همه خانه‌ها باید پر شوند.
7. قبل از کامل شدن ۶ رقم، دکمه تأیید باید غیرفعال باشد.
8. تایمر `02:00` باید شروع شود و کاهش پیدا کند.
9. بعد از صفر شدن، «ارسال مجدد کد» باید فعال شود.
10. ارسال مجدد باید کد تازه بفرستد و تایمر دوباره شروع شود.
11. با کد صحیح، ورود انجام شود و کاربر به مسیر قبلی برگردد.
12. با کد اشتباه/منقضی، پیام فارسی مناسب نشان داده شود.
