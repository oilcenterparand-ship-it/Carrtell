# Carrtell RC1-03B — راه‌اندازی متمرکز مدیریت

این نسخه ساخت اولین Super Admin را از داخل خود سایت انجام می‌دهد و برای این کار به Supabase CLI یا Edge Function نیاز ندارد.

## نصب

1. فایل‌های پچ را داخل ریشه پروژه جایگزین کن.
2. فایل زیر را کامل در Supabase SQL Editor اجرا کن:

`supabase/migrations/202607230004_rc1_03_admin_rbac.sql`

3. پروژه را اجرا کن:

```powershell
npm run dev
```

4. فقط برای اولین بار برو به:

`http://localhost:5173/admin/setup`

5. نام، نام کاربری انگلیسی و رمز حداقل ۱۰ کاراکتری را وارد کن.
6. حساب Super Admin ساخته می‌شود و صفحه Setup بعد از آن خودکار و دائمی قفل خواهد شد.
7. ورودهای بعدی فقط از آدرس زیر است:

`http://localhost:5173/admin/login`

## نکته امنیتی

تابع Bootstrap فقط زمانی کار می‌کند که جدول مدیران کاملاً خالی باشد. پس از ساخت اولین مدیر، حتی کاربر ناشناس نیز نمی‌تواند حساب دیگری از صفحه Setup ایجاد کند. مدیران بعدی باید از بخش «کاربران و دسترسی‌ها» در خود پنل ساخته شوند.
