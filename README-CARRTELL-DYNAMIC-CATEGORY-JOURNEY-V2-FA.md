# پچ مسیر داینامیک دسته‌بندی Carrtell V2

## نتیجه
- ساخت شاخه و زیرشاخه نامحدود از پنل مدیریت
- دکمه «+ زیرشاخه» کنار هر دسته
- نمایش مسیر کامل هر شاخه در پنل
- انتخاب شاخه والد با مسیر کامل
- نمایش فقط شاخه‌های نهایی در فرم محصول
- الزام انتخاب حداقل یک شاخه نهایی برای محصول جدید
- صفحه عمومی `/categories`
- مسیر داینامیک `/category/:slug`
- نمایش مرحله بعد تا رسیدن به محصول نهایی
- Breadcrumb کامل برای برگشت به مراحل قبل

## نمونه ساخت روغن 15W-40
1. دسته `روغن‌ها` بساز.
2. کنار آن `+ زیرشاخه` بزن و `روغن موتور` را بساز.
3. زیر `روغن موتور` شاخه `گرید روغن` را بساز.
4. زیر `گرید روغن` شاخه `15W-40` را بساز.
5. در پنل محصولات، محصول را به مسیر نهایی `روغن‌ها ← روغن موتور ← گرید روغن ← 15W-40` وصل کن.

## نمونه فیلتر سرکان
`فیلترها ← فیلتر روغن ← برند ← سرکان`

تمام محصولات فیلتر روغن سرکان را به شاخه نهایی `سرکان` متصل کن.

## نصب
ZIP را در ریشه پروژه استخراج و Replace کن. SQL جدیدی لازم نیست؛ Migration پچ V1 باید قبلاً اجرا شده باشد.

```powershell
npm install
npm run typecheck
npm run build
.\agent-category.ps1
```

اگر Agent شکست خورد، اولین بخش `FAILED` و گزارش Playwright را برای ساخت پچ اصلاحی بفرست.
