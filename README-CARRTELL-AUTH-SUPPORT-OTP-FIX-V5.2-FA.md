## تغییرات

### 1. دکمه پشتیبانی موبایل
- آیکون واتساپ حذف شد.
- آیکون جدید «هدست پشتیبانی» اضافه شد.
- دکمه به `/profile/support` می‌رود.
- در مسیرهای مستقل موبایل مثل رزرو و حساب، دکمه شناور مخفی می‌شود تا روی فرم و CTA گیر نکند.
- در سایر صفحات، دکمه با Safe Area پایین صفحه هماهنگ است.

### 2. متن توضیحات سرویس‌کار
Placeholder جدید:

`توضیحات لازم برای آدرس‌دهی بهتر و یا مورد خاص در ارائه سرویس (مثلاً پیچ کارتل ماشینم خرابه)`

### 3. OTP قبل از پرداخت
- ارسال OTP در رزرو همچنان قبل از پرداخت است.
- اگر درخواست اول به‌صورت موقت Fail شود، یک Retry کنترل‌شده خودکار انجام می‌شود.
- اگر هر دو تلاش Fail شوند، کاربر پیام خطای خوانا می‌بیند و می‌تواند دوباره «ارسال کد» را بزند.
- مسیر «ادامه بدون OTP» وجود ندارد؛ پرداخت فقط بعد از تأیید شماره فعال می‌شود.
- بعد از ارسال موفق، باکس ورود کد حتماً نمایش داده می‌شود.

### 4. ورود سراسری
- ورود Supabase یک Session سراسری برای کل سایت است.
- Header و منوی پایین هنگام رفتن به Login، `returnTo` صفحه فعلی را حفظ می‌کنند.
- اگر کاربر از صفحه اصلی، حساب، یا رزرو وارد شود، همان Session در تمام سایت استفاده می‌شود.
- در رزرو، اگر شماره حساب قبلاً تأیید شده باشد OTP دوم درخواست نمی‌شود.
- ورود OTP داخل رزرو نیز Session واقعی سایت را فعال می‌کند.

### 5. نام کاربر و سلام در منوی موبایل
- در ورود پیامکی «نام و نام خانوادگی» گرفته می‌شود.
- نام در Profile ذخیره می‌شود.
- زیر آیکون حساب در منوی پایین، بعد از ورود نام کوچک نمایش داده می‌شود؛ مثال: `سلام زهرا`.
- اگر OTP از مسیر رزرو انجام شود، نامی که در مرحله اطلاعات رزرو وارد شده نیز در Profile ذخیره می‌شود.

### 6. حذف حساب
- `window.confirm` مرورگر حذف شد و تأیید داخل خود UI انجام می‌شود.
- روند جدید:
  1. حذف حساب کاربری
  2. هشدار داخلی
  3. ارسال کد و ادامه
  4. ورود OTP
  5. تأیید و حذف دائمی
- خطای `{}` دیگر به کاربر نمایش داده نمی‌شود؛ خطای OTP به متن خوانا تبدیل می‌شود.
- Edge Function `customer-account-delete` همان Function قبلی است و در V5.1 Deploy شده؛ این Sprint Function جدید یا SQL ندارد.

## نصب Patch
ZIP را در ریشه پروژه Extract/Replace کنید:

`D:\carrtell\Carrtell-v0.2-current\project`

سپس:

```powershell
npm run typecheck
npm run build

$env:CARRTELL_ADMIN_USERNAME="admin"
$env:CARRTELL_ADMIN_PASSWORD="12345678"
$env:CARRTELL_TECH_USERNAME="service"
$env:CARRTELL_TECH_PASSWORD="12345678"

.\agent.ps1 PERSONAS
```

حالت `PERSONAS` حالا علاوه بر تست‌های قبلی، Regression جدا برای Login / OTP Retry / Support / Account Delete را هم اجرا می‌کند.

## تست دستی موبایل بعد از PASS
1. از صفحه اصلی وارد Login شوید؛ نام + موبایل را وارد کنید و OTP را تأیید کنید. زیر آیکون حساب باید `سلام <نام>` دیده شود.
2. وارد رزرو شوید؛ اگر قبلاً Login هستید مرحله آخر نباید OTP دوم بخواهد.
3. به‌صورت مهمان رزرو کنید؛ مرحله آخر شماره را بگیرد، ارسال کد موفق باید باکس OTP را نشان دهد و بعد از تأیید Session کل سایت فعال شود.
4. در `حساب من > پروفایل` حذف حساب را بزنید؛ باید هشدار داخلی باز شود، نه هیچ‌اتفاق یا `{}`.
5. در فروشگاه آیکون هدست پشتیبانی را بررسی کنید؛ در صفحه رزرو نباید روی فرم شناور باشد.
