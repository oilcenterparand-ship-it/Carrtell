# Carrtell V3.5.0 — محاسبه کرایه رزرو سرویس

## رفتار نهایی

- مبدأ کرایه: نقطه ارسال‌شده در نشان با مختصات `35.6505318, 51.2740074`
- کرایه پایه: `۲۰۰٬۰۰۰ تومان`
- هر کیلومتر مسیر از مبدأ تا مشتری: `۱۰٬۰۰۰ تومان` (اعشار کیلومتر رو به بالا گرد می‌شود)
- محدوده مجاز: شعاع `۴۰ کیلومتری` مرکز تهران
- مقصد خارج محدوده: امکان ادامه رزرو ندارد
- مقصد داخل محدوده طرح ترافیک: `۳۰٪` افزایش روی کرایه مسیر
- فاصله و کرایه در مرحله لوکیشن، خلاصه رزرو، پرداخت و تصویر فاکتور نمایش داده می‌شود
- مبدأ، مرکز، شعاع، مبلغ پایه، نرخ کیلومتر و درصد طرح از پنل ادمین قابل تغییر است

کلید سرویس نشان فقط در Secret مربوط به Supabase Edge Function استفاده می‌شود و وارد Frontend یا ZIP نشده است. استعلام کرایه ۳۰ دقیقه اعتبار دارد و دیتابیس هنگام ثبت رزرو، مقصد و مبلغ آن را دوباره کنترل می‌کند.

## ترتیب نصب

1. ZIP را در ریشه پروژه Extract و Replace کنید.
2. فایل `supabase/manual/CARRTELL_SERVICE_TRAVEL_PRICING_SAFE.sql` را در Supabase SQL Editor اجرا کنید.
3. Edge Function را Deploy کنید:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
npx supabase functions deploy service-travel-estimate --no-verify-jwt
```

Secret قبلی `NESHAN_SERVICE_API_KEY` باید در Supabase باقی مانده باشد. مقدار Secret را در چت، Frontend یا GitHub وارد نکنید.

4. تست‌ها را اجرا کنید:

```powershell
npm run typecheck
npm run build
.\agent.ps1 BOOKING
```

به‌علت سابقه تداخل شماره Migrationهای پروژه، برای این تحویل `npx supabase db push` اجرا نکنید.

## تست دستی

1. `/book` را در موبایل و دسکتاپ باز کنید.
2. مراحل را تا انتخاب موقعیت ادامه دهید.
3. یک نقطه داخل تهران انتخاب و تأیید کنید؛ فاصله و کرایه باید نمایش داده شود.
4. نقطه‌ای داخل طرح ترافیک انتخاب کنید؛ پیام افزایش درصد باید نمایش داده شود.
5. نقطه‌ای بیش از ۴۰ کیلومتر از مرکز تهران انتخاب کنید؛ ادامه رزرو باید متوقف شود.
6. رزرو آزمایشی را پرداخت و فاکتور تصویری را دریافت کنید؛ «فاصله مسیر»، «هزینه رفت‌وآمد» و در صورت لزوم «افزایش محدوده طرح ترافیک» باید درج شده باشد.
