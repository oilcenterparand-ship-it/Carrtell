مرحله ۱۰ Carrtell — کارت محصول، دسته‌بندی و بنر

تغییرات:
- کارت محصولات کمی بزرگ‌تر، خواناتر و منظم‌تر شد.
- فضای تصویر، عنوان، قیمت و دکمه افزودن به سبد خرید ثابت‌تر شد.
- Hover و سایه کارت‌ها حرفه‌ای‌تر شد.
- بنر اصلی دارای گرادیان خوانایی، دکمه طلایی و نشانگر اسلاید واضح‌تر شد.
- کارت‌های دسته‌بندی از حالت ساده به کارت‌های جمع‌وجور و انتخاب‌پذیر تبدیل شدند.
- دسته‌بندی فعال با رنگ برند مشخص می‌شود.
- گزینه نمایش همه برای حذف فیلتر دسته‌بندی اضافه شد.
- منطق سبد خرید، فیلتر، پنل مدیریت و دیتابیس تغییر نکرده است.

وضعیت تست:
- npm run build: موفق
- هشدارهای قدیمی فونت، ترتیب @import و حجم bundle همچنان موجودند و مربوط به این مرحله نیستند.
