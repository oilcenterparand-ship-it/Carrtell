Carrtell RC1-05A - Mobile First

نصب:
1) محتویات این ZIP را در مسیر زیر Extract و Replace کنید:
D:\carrtell\Carrtell-v0.2-current\project

2) سپس اجرا کنید:
npm run typecheck
npm run build

3) برای انتشار، محتویات پوشه dist را مانند قبل در public_html جایگزین کنید.

تغییرات:
- نوار پایین ثابت موبایل: خانه، فروشگاه، سرویس، سفارش‌ها، حساب
- هدر موبایل دو ردیفه و جمع‌وجور
- لوگو و دکمه‌های هدر بدون هم‌پوشانی
- منوی موبایل به Bottom Sheet تبدیل شد
- انتخاب خودرو در موبایل به پنل پایین و تمام‌عرض تبدیل شد
- شبکه‌های چندستونه محصولات در موبایل دو ستونه شدند
- فرم‌های چندستونه در موبایل تک‌ستونه شدند
- ورودی‌ها برای جلوگیری از زوم خودکار iOS روی 16px تنظیم شدند
- کنترل overflow افقی و safe-area موبایل
- نوار پایین در پنل مدیریت، سرویس‌کار، ورود و پرداخت نمایش داده نمی‌شود

بررسی انجام‌شده:
- TypeScript بدون خطا است.
- Build در محیط سازنده به دلیل Permission denied فایل اجرایی Vite قابل اجرا نبود؛ این خطا مربوط به مجوز محیط است، نه TypeScript.
