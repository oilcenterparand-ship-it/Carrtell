# RC1-06C — جستجو و رزرو موبایل

## اصلاحات
- جلوگیری از زوم خودکار Safari هنگام لمس جستجو با فونت 16px.
- نمایش نتایج جستجو در پنل موبایلی قابل مشاهده.
- جستجو بر اساس نام محصول، برند و خودروهای سازگار.
- جلوگیری از سفید شدن کارت‌های روز و ساعت در لمس/انتخاب.
- انتخاب خودرو در رزرو با پنجره اختصاصی، جستجو، انتخاب و دکمه تأیید.
- قفل شدن اسکرول صفحه پشت پنجره انتخاب خودرو.

## نصب
محتویات ZIP را داخل ریشه پروژه Replace کنید.

سپس:

```powershell
npm run typecheck
npm run build
```

SQL جدید لازم نیست.
