# Carrtell RC1-03D — بازسازی نهایی ورود مدیریت

این نسخه حساب ناقص ساخته‌شده در مراحل قبل را تعمیر می‌کند و همان کاربر Auth را به Super Admin واقعی متصل می‌کند.

## نصب
1. فایل‌های پچ را در ریشه پروژه Replace کنید.
2. فایل زیر را کامل در Supabase SQL Editor اجرا کنید:

`supabase/migrations/202607230006_rc1_03d_admin_rebuild.sql`

3. پروژه را اجرا کنید:

`npm run dev`

4. آدرس زیر را باز کنید:

`http://localhost:5173/admin/setup`

5. نام کاربری قبلی (`aminoraei`) و یک رمز جدید حداقل ۱۰ کاراکتری وارد کنید.

پس از موفقیت، سیستم همان حساب Auth را تعمیر، ردیف مدیریتی را هم‌تراز، نقش owner را اعمال و شما را وارد داشبورد می‌کند.

ورودهای بعدی:

`http://localhost:5173/admin/login`
