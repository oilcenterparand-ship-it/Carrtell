# Carrtell Baseline Header + Category Patch

این پچ فقط روی نسخه پایه project(2)(1) طراحی شده است.

تغییرات:
- هدر باریک‌تر و تیره‌تر
- جستجو و آیکون‌های هماهنگ با هدر
- حذف نوار بزرگ زرد انتخاب خودرو از صفحه اصلی
- افزودن نوار باریک دسته‌بندی زیر هدر
- بدون تغییر در قابلیت‌ها، دیتابیس و پنل مدیریت

اجرا:
```powershell
node scripts/apply-baseline-header-category.mjs
```
