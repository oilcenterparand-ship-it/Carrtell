Carrtell order review + invoice + mini cart patch

Features:
- Orders start as pending_review / در انتظار بررسی.
- Admin can confirm order and move it to processing / در حال آماده‌سازی.
- Customer profile shows invoice download/print link.
- /invoice/:orderId printable invoice page for PDF save.
- Header cart icon opens mini cart with quantity +/- and delete.
- Internal admin_notifications row is created for each new order.

Note: Real SMS/mobile notification requires connecting an SMS provider or PWA push in the next step.
