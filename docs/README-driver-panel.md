# Carrtell Driver Panel

Route: `/driver`

What it adds:
- Shows service requests ready for dispatch.
- Driver can set status to dispatching, en route, arrived, or completed.
- Driver can save technician name locally.
- On completion, current kilometer can be saved and next service kilometer is recalculated.
- Map link uses saved latitude/longitude when available.

No real Neshan connection is added in this patch.
