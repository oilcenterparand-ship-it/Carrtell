# Carrtell - تخصیص سرویس‌کار و گردش عملیات سرویس

این پچ مرحله عملیات سرویس در محل را کامل‌تر می‌کند.

## امکانات

- انتخاب سرویس‌کار از بین کاربران با نقش `driver`
- ذخیره `assigned_driver_id`، نام و موبایل سرویس‌کار روی درخواست سرویس
- نمایش فقط مأموریت‌های همان سرویس‌کار در مسیر `/driver`
- گردش وضعیت کامل:
  - در انتظار بررسی
  - تأیید شده
  - تخصیص داده شده
  - اعزام سرویس‌کار
  - در مسیر مشتری
  - رسیده به محل
  - در حال انجام سرویس
  - تکمیل شده
  - لغو شده
- ثبت کیلومتر پایان سرویس
- ثبت محصولات مصرف‌شده و گزارش پایان سرویس
- آماده برای تصاویر قبل/بعد و اتصال Storage در مرحله بعد

## نکته مهم Supabase

`supabase/migrations/20260706_service_driver_assignment.sql`
