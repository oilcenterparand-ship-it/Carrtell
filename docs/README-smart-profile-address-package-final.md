# Carrtell Smart Profile + Address + Package Final Patch

این پچ شامل این موارد است:

- حذف منطق ساخت پکیج خودکار؛ سایت فقط پکیج‌های فعال و ساخته‌شده از پنل را پیشنهاد می‌دهد.
- دسته‌های پیش‌فرض پکیج در پنل مدیریت پکیج‌ها: اقتصادی، ویژه، حرفه‌ای، مراقبت خودرویی، سرویس دوره‌ای، تابستانه، زمستانه، افزایش عملکرد.
- هدر سایت: آیکون خانه و اتصال آیکون آدمک به پروفایل.
- پروفایل کاربری: ورود با شماره موبایل و OTP تستی، اطلاعات مشتری، خودروهای من، آدرس‌های منتخب و یادآوری سرویس کیلومتری.
- آدرس‌های منتخب: خانه/محل کار/سایر، استان، شهر، محله، خیابان، پلاک، واحد و مختصات آماده اتصال به نشان.
- سبد خرید: انتخاب آدرس ذخیره‌شده یا ورود دستی آدرس قبل از ثبت سفارش.
- منوی سه‌خط و MiniCart از نسخه‌های اصلاح‌شده حفظ شده‌اند.
- آپلود هوشمند محصول، WebP، کم‌حجم‌سازی و واترمارک برگشته است.

بعد از جایگزینی فایل‌ها، SQL داخل `database/smart_profile_address_package_final.sql` را در Supabase اجرا کنید.
