# Carrtell next stage patch

این پچ برای ادامه پروژه است و چند اصلاح پایداری هم دارد:

- ثبت سفارش بعد از ساخت سفارش به `/payment?orderId=...` می‌رود.
- صفحه پرداخت با تم تیره و هماهنگ نمایش داده می‌شود و بعداً آماده اتصال به درگاه واقعی است.
- پنل سفارش‌ها workflow سریع دارد: تأیید و آماده‌سازی، ارسال/در مسیر، تحویل شد + لینک نظر.
- بعد از تحویل سفارش، لینک نظرسنجی قابل مشاهده و کپی است.
- سرویس `selectedCar` داخل پچ قرار گرفت تا انتخاب خودروی کاربر در هدر/فروشگاه پایدار بماند.
- چند خطای TypeScript و overwrite ناقص پچ‌های قبلی اصلاح شد.

بعد از کپی فایل‌ها اجرا کن:

```bash
npm run dev
```

برای چک تایپ:

```bash
npm run typecheck
```
