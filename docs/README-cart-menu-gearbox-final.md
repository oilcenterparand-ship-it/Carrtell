# Carrtell patch

این پچ سه اصلاح دارد:

1. برگشت منوی سه‌خط به حالت کادر کوچک و هماهنگ با تم، همراه با لیست دسته‌بندی‌ها.
2. برگشت Mini Cart واقعی و کوچک با اسکرول داخلی محصولات و فوتر ثابت.
3. اضافه شدن سازگاری گیربکس/واسکازین در پنل محصولات.

SQL فایل `database/product_transmission_compatibility.sql` را در Supabase اجرا کن.
