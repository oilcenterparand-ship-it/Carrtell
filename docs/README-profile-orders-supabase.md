# Carrtell profile orders patch

این پچ بخش سفارش‌های پروفایل کاربری را از localStorage جدا می‌کند و مستقیم از جدول orders در Supabase بر اساس شماره موبایل مشتری می‌خواند.

تغییرات:
- دریافت سفارش‌های مشتری از Supabase با getOrdersByPhone
- نمایش وضعیت فارسی سفارش با badge هماهنگ با تم
- دکمه بروزرسانی سفارش‌ها
- دانلود فاکتور PDF واقعی از سفارش و آیتم‌های سفارش
- لینک مشاهده فاکتور و ثبت نظر برای هر سفارش
