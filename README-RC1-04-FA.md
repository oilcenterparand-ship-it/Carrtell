# Carrtell RC1-04 — سرویس در محل

## امکانات این پچ
- انتخاب موقعیت دقیق مشتری روی نقشه در فرم رزرو
- ذخیره طول و عرض جغرافیایی همراه درخواست سرویس
- حذف فیلد جداگانه شهر از فرم مشتری و استفاده از آدرس/موقعیت
- رزرو اتمیک ظرفیت بازه زمانی برای جلوگیری از ثبت هم‌زمان بیشتر از ظرفیت
- آزاد شدن ظرفیت پس از لغو درخواست
- آماده‌سازی مختصات زنده تکنسین و علت لغو در دیتابیس
- حفظ صفحات موجود مدیریت خدمات، ظرفیت‌ها، درخواست‌ها و ناوگان

## نصب
1. محتوای ZIP را روی پوشه پروژه Replace کنید.
2. فایل زیر را در Supabase SQL Editor کامل اجرا کنید:
   `supabase/migrations/202607230009_rc1_04_onsite_service_complete.sql`
3. پروژه را دوباره اجرا کنید:
   `npm run dev`
4. مرورگر را با `Ctrl + Shift + R` تازه‌سازی کنید.

## تنظیم نقشه نشان
در فایل `.env.local` این دو مقدار را وارد کنید:

```env
VITE_NESHAN_MAP_KEY=YOUR_MAP_KEY
VITE_NESHAN_SERVICE_KEY=YOUR_SERVICE_KEY
```

بدون کلید نشان، نقشه با OpenStreetMap باز می‌شود؛ جست‌وجو و تبدیل مختصات به آدرس به کلید سرویس نشان نیاز دارد.

## تست
- `/book`: ثبت رزرو با انتخاب نقطه روی نقشه
- `/admin/service-booking-settings`: خدمات، بازه و ظرفیت
- `/admin/service-requests`: تأیید، تخصیص و تغییر وضعیت
- `/admin/service-fleet`: تکنسین و خودروهای سرویس
