# بازگردانی نوار دسته‌بندی صفحه اصلی V3.1.4

نوار دسته‌بندی صفحه اصلی که به‌دلیل شرط ثابت `false` حذف شده بود بازگردانده شد.

- فقط در صفحه اصلی `/` نمایش داده می‌شود.
- صفحه فروشگاه همچنان Mega Menu داینامیک خودش را دارد.
- صفحات پرداخت، حساب و جزئیات محصول شلوغ نمی‌شوند.
- تست عدم حذف مجدد نوار به ایجنت اضافه شد.
- SQL و Edge Function ندارد.

پس از Extract و Replace در ریشه پروژه:

```powershell
npm run typecheck
npm run build
.\agent-category.ps1
```
