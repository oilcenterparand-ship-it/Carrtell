# راهنمای پچ منوی آبشاری دسته‌بندی Carrtell V2.2

این پچ نمایش دسته‌بندی فروشگاه را به ساختار مرحله‌ای تبدیل می‌کند:

`دسته مادر ← زیرشاخه ← زیرشاخه بعدی ← محصولات`

## نتیجه

- نوار سریع فروشگاه فقط دسته‌های مادر را نمایش می‌دهد.
- دسکتاپ زیرشاخه‌ها را در ستون‌های مجزا و پویا باز می‌کند.
- موبایل هر سطح را در یک مرحله نشان می‌دهد و دکمه بازگشت دارد.
- تعداد عمق دسته‌بندی محدود و هاردکد نشده است.
- انتخاب دسته مادر، محصولات متصل به همه زیرشاخه‌های آن را هم فیلتر می‌کند.
- مدیریت دسته‌ها همچنان از پنل ادمین و به‌صورت Dynamic انجام می‌شود.

## نصب

محتویات ZIP را در ریشه پروژه Extract و فایل‌های هم‌نام را Replace کنید. سپس:

```powershell
npm run typecheck
npm run build
.\agent-category.ps1
```

## تست دستی موبایل

1. فروشگاه را باز کنید و «دسته‌بندی محصولات» را بزنید.
2. «دیزلی و صنعتی» را انتخاب کنید.
3. «فیلترهای صنعتی و دیزلی» را انتخاب کنید.
4. یکی از انواع فیلتر را بزنید و فهرست محصولات را کنترل کنید.
5. دکمه بازگشت را در هر مرحله امتحان کنید.

## دیتابیس

SQL جدیدی لازم نیست. این پچ از `parent_id` و `product_category_assignments` موجود در Migration V1 استفاده می‌کند.
