# اصلاح اندازه و نوار دسته‌بندی طرح ۳ — نسخه ۳.۳.۱

این پچ پس از نسخه ۳.۳ نصب می‌شود و براساس تصویر واقعی مرورگر با ابعاد ۱۳۶۵ در ۷۶۸ تنظیم شده است.

## اصلاحات

- هدر دسکتاپ صفحه اصلی حدود ۱۵ تا ۱۸ درصد کوچک‌تر شده است.
- پنجره دسته‌بندی حدود ۲۰ تا ۲۵ درصد کوچک‌تر شده است.
- عرض پنجره حداکثر ۱۰۸۰ پیکسل است.
- ارتفاع پنجره حداکثر ۳۴۸ پیکسل است و با فضای واقعی مرورگر تنظیم می‌شود.
- کارت دسته مادر، آیکون‌ها، عنوان‌ها و دکمه تبلیغ کوچک‌تر شده‌اند.
- تبلیغ کاملاً داخل پنجره می‌ماند.
- نوار روشن قبلی با نوار سرمه‌ای طرح ۳ جایگزین شده است.
- نوار فقط دسته‌های مادر داینامیک را نمایش می‌دهد.
- با قرارگرفتن موس روی دکمه دسته‌بندی، منوی آبشاری خودکار باز می‌شود.
- کلیک روی دکمه همچنان کار می‌کند.

## محدوده ایمن

فایل‌های منوی پایین موبایل و رزرو سرویس تغییر نکرده‌اند. این پچ به اس‌کیوال یا تابع لبه جدید نیاز ندارد.

## نصب

ابتدا پیش‌نمایش را با `Ctrl + C` متوقف کنید. فایل فشرده را در ریشه پروژه استخراج و جایگزینی فایل‌ها را تأیید کنید.

اگر فایل را دستی استخراج کرده‌اید، دستور `Expand-Archive` را اجرا نکنید.

سپس:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"

npm run typecheck
npm run build
.\agent-category.ps1
```

برای مشاهده:

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

مسیرهای بررسی:

```text
http://127.0.0.1:4173/
http://127.0.0.1:4173/shop
```
