# پچ طراحی ۳ منوی دسته‌بندی کارتل — نسخه ۳.۳

این پچ فقط ظاهر و آزمون منوی دسته‌بندی داینامیک را تغییر می‌دهد.

## نتیجه

- دسکتاپ: دسته‌های مادر به‌صورت کارت‌های کوچک در سمت راست، زیرشاخه‌های آبشاری در میانه و تبلیغ قابل‌مدیریت در سمت چپ نمایش داده می‌شوند.
- موبایل: منوی جمع‌وجور زیر نوار دسته‌بندی باز می‌شود، دسته‌های مادر در ردیف افقی دیده می‌شوند و زیرشاخه‌ها مرحله‌به‌مرحله با دکمه بازگشت باز می‌شوند.
- صفحه اصلی و فروشگاه هر دو از زبان بصری انتخاب‌شده استفاده می‌کنند.
- نام و شناسه هیچ دسته‌ای در کد ثابت نشده است و عمق درخت می‌تواند داینامیک باشد.

## بخش‌هایی که تغییر نکرده‌اند

- منوی پایین موبایل
- مراحل رزرو سرویس
- سبد خرید و پرداخت
- ورود مشتری و ادمین
- انتخاب خودرو
- دیتابیس، مهاجرت‌ها و توابع لبه

این نسخه به اس‌کیوال جدید یا استقرار تابع لبه نیاز ندارد.

## نصب

پیش‌نمایش در حال اجرا را با کلیدهای `Ctrl + C` متوقف کنید.

فایل فشرده را داخل ریشه پروژه قرار دهید:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
```

اگر فایل را هنوز استخراج نکرده‌اید:

```powershell
Expand-Archive `
  -LiteralPath ".\CARRTELL-DYNAMIC-MEGA-MENU-DESIGN-3-V3.3.0.zip" `
  -DestinationPath "." `
  -Force
```

اگر با کلیک راست فایل را در ریشه پروژه استخراج و جایگزین کرده‌اید، دستور `Expand-Archive` را اجرا نکنید.

## آزمون

```powershell
npm run typecheck
npm run build
.\agent-category.ps1
```

ایجنت نام کاربری واقعی ادمین را هنگام اجرا می‌پرسد. رمز به‌صورت مخفی دریافت می‌شود و پس از پایان یا شکست آزمون از محیط پاک می‌شود.

برای مشاهده نتیجه:

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

سپس این مسیرها را بررسی کنید:

```text
http://127.0.0.1:4173/
http://127.0.0.1:4173/shop
http://127.0.0.1:4173/book
```

## انتشار روی هاست

پس از پاس‌شدن آزمون‌ها فقط خروجی جدید ساخت را جایگزین کنید:

- پوشه `public_html/assets` با پوشه جدید `dist/assets`
- فایل `public_html/index.html` با فایل جدید `dist/index.html`

فایل‌های `.htaccess`، پوشه `cgi-bin`، فایل تأیید اینماد و فایل‌های اختصاصی هاست را حذف نکنید.
