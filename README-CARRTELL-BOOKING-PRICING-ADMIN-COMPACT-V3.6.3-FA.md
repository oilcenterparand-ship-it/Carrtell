# Carrtell V3.6.3 — قیمت‌گذاری مدیریتی و نقشه جمع‌وجور

این پچ روی V3.6.2 نصب می‌شود و SQL جدید یا تغییر Secret ندارد.

## تغییرات

- مرحله ۵ مبلغ و فاصله کرایه را نمایش نمی‌دهد؛ فقط تأیید موقعیت و پیام آماده‌شدن هزینه نشان داده می‌شود.
- فاصله و کرایه فقط در مرحله ۶، خلاصه نهایی، پرداخت و فاکتور نمایش داده می‌شود.
- ارتفاع نقشه رزرو در دسکتاپ از ۳۳۰ به ۲۳۵ پیکسل کاهش یافته؛ موبایل ۳۳۰ پیکسل باقی مانده است.
- تمام عوامل قیمت‌گذاری در پنل `تنظیمات رزرو هوشمند سرویس` قابل تغییر هستند:
  - کرایه پایه و هر کیلومتر
  - مبدأ کرایه
  - مرکز و شعاع خدمات
  - درصد و مرز طرح ترافیک
  - هزینه شب، تعطیلات و خارج محدوده
  - ساعت شروع شب
  - تخفیف باشگاه
  - شهرهای داخل محدوده
- پیام موفقیت فقط پس از ذخیره واقعی در Supabase نمایش داده می‌شود.

## نصب

ZIP را در ریشه پروژه Extract و Replace کنید، سپس:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
npm run typecheck
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

پس از تست، محتویات `dist` را روی `public_html` جایگزین کنید.

## تست

1. در مرحله ۵ رزرو، کرایه و فاصله نباید نمایش داده شود.
2. در مرحله ۶، فاصله و هزینه رفت‌وآمد باید دیده شود.
3. در دسکتاپ، نقشه باید بدون اسکرول طولانی در کادر مرحله جا شود.
4. در پنل مدیریت، یک مبلغ آزمایشی تغییر دهید و ذخیره کنید؛ پیام باید صریحاً ذخیره در سرور را تأیید کند.
