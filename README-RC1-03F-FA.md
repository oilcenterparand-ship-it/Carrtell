# RC1-03F — تکمیل نقش‌ها و کاربران پنل

این پچ مشکلات زیر را رفع می‌کند:

- باز نشدن فیلد نقش هنگام ساخت کاربر
- خالی بودن لیست نقش‌ها
- نبود امکان ساخت نقش جدید
- نبود امکان ویرایش نقش سفارشی
- وابستگی ساخت کاربر مدیریتی به Edge Function

## نصب

1. تمام محتوای ZIP را در ریشه پروژه کپی و Replace کنید.
2. فایل زیر را کامل در Supabase SQL Editor اجرا کنید:

`supabase/migrations/202607230008_rc1_03f_roles_accounts_complete.sql`

3. پروژه را مجدداً اجرا کنید:

```powershell
Ctrl + C
npm run dev
```

4. مرورگر را با `Ctrl + Shift + R` رفرش کنید.

## تست

- مسیر `/admin/roles`: ساخت یک نقش سفارشی و سپس ویرایش آن
- مسیر `/admin/admin-accounts`: باز شدن فهرست نقش‌ها و ساخت یک کاربر آزمایشی
- خروج و ورود با کاربر آزمایشی برای بررسی محدودیت دسترسی

نقش‌های سیستمی عمداً قابل ویرایش و حذف نیستند. برای تغییر مجوزها یک نقش سفارشی بسازید.
