# پچ منوی دسته‌بندی داینامیک پریمیوم کارتل

نسخه: ۳.۲.۰

این پچ نوار دسته‌بندی قدیمی صفحه اصلی را با منوی تیره و طلایی طرح شماره ۳ جایگزین می‌کند.

## نتیجه پچ

- صفحه اصلی فقط یک دکمه اصلی «دسته‌بندی محصولات» و میانبرهای فروشگاه دارد.
- منوی دسکتاپ روی صفحه باز می‌شود و محتوای سایت از پشت آن دیده می‌شود.
- ستون‌های منو براساس درخت واقعی دسته‌بندی‌ها ساخته می‌شوند.
- هیچ نام یا اسلاگ ثابتی برای انتخاب شاخه اولیه استفاده نمی‌شود.
- در موبایل، دسته مادر درشت‌تر است و زیرشاخه‌ها مرحله‌به‌مرحله باز می‌شوند.
- دکمه بازگشت در تمام مراحل موبایل وجود دارد.
- تبلیغ منو از پنل مدیریت قابل تغییر است.
- پنل ادمین اجازه انتخاب یک زیرشاخه به‌عنوان والد خودش یا ساخت چرخه را نمی‌دهد.
- محصول فقط از فهرست شاخه‌های نهایی داینامیک انتخاب می‌شود.

## نصب

فایل زیپ را در ریشه پروژه استخراج و فایل‌ها را جایگزین کن.

مسیر پروژه:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
```

## دیتابیس

فایل زیر را یک‌بار داخل ویرایشگر اس‌کیوال سوپابیس اجرا کن:

```text
supabase/migrations/202608230003_category_tree_cycle_guard.sql
```

این فایل اطلاعات دسته‌بندی را حذف یا بازنویسی نمی‌کند. فقط از ایجاد رابطه حلقه‌ای جلوگیری می‌کند.

## تست

```powershell
npm run typecheck

npm run build

.\agent-category.ps1
```

ایجنت نام کاربری واقعی ادمین را هنگام اجرا می‌پرسد. رمز به‌صورت مخفی دریافت می‌شود و پس از پایان تست از محیط همان اجرا پاک می‌شود.

## بررسی دستی

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

سپس این نشانی را باز کن:

```text
http://127.0.0.1:4173
```

موارد زیر را بررسی کن:

۱. دکمه دسته‌بندی جدید در صفحه اصلی دیده شود.

۲. در دسکتاپ منوی تیره و طلایی با چند ستون باز شود.

۳. در موبایل شاخه‌ها مرحله‌به‌مرحله باز شوند و بازگشت کار کند.

۴. صفحه فروشگاه همچنان منوی داینامیک خودش را داشته باشد.

۵. منوی اضافی در پرداخت، حساب کاربری و جزئیات محصول دیده نشود.

۶. در پنل مدیریت بتوان دسته مادر، زیرشاخه، ترتیب، تصویر، آیکون و وضعیت فعال را تغییر داد.

۷. در پنل صفحه اصلی بتوان تصویر، عنوان، متن، نشان، دکمه، لینک و وضعیت تبلیغ منو را تغییر داد.

## انتشار روی هاست

پس از ساخت، فقط محتوای جدید پوشه زیر را داخل هاست جایگزین کن:

```text
dist
```

این موارد نباید حذف شوند:

```text
.htaccess
cgi-bin
فایل تأیید اینماد
فایل‌های اختصاصی هاست
```

فقط خروجی جدید، مخصوصاً پوشه دارایی‌ها و فایل اصلی صفحه، جایگزین شود.
