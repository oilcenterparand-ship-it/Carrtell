# RC1-06B — اصلاح مسیرهای موبایل Carrtell

این پچ روی نسخه project(31) ساخته شده و شامل موارد زیر است:

- حذف هدر عمومی در موبایل برای صفحه رزرو سرویس و نمای مستقیم سفارش‌ها
- مرتب‌سازی و فشرده‌سازی کارت‌های سفارش در موبایل
- بهینه‌سازی اجزای صفحه سرویس برای موبایل
- افزودن دسته‌بندی افقی واقعی و جستجوی باریک در صفحه همه محصولات
- مرتب‌سازی محصولات بر اساس دسته و نام به‌جای نمایش نامرتب
- اصلاح پنجره انتخاب خودرو: قفل اسکرول پس‌زمینه، اسکرول مستقل، دکمه بازگشت و حاشیه مشخص

## نصب
محتویات ZIP را داخل ریشه پروژه کپی و فایل‌های هم‌نام را Replace کنید.

مسیر پروژه:
D:\carrtell\Carrtell-v0.2-current\project

سپس:

npm run typecheck
npm run build

بعد محتویات dist جدید را داخل public_html جایگزین کنید.

## وضعیت بررسی
npm run typecheck بدون خطا اجرا شد.
Build در محیط تولید پچ به دلیل نبود optional dependency لینوکسی Rollup اجرا نشد؛ این وابستگی مختص محیط سازنده است و روی ویندوز کاربر با npm install موجود باید Build اجرا شود.

SQL جدید لازم نیست.
