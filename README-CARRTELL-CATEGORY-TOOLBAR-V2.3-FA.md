# پچ نوار دسته‌بندی Carrtell V2.3

## تغییرات

- کارت‌های متعدد دسته‌بندی از نوار فروشگاه حذف شدند.
- یک دکمه اصلی و پررنگ «دسته‌بندی محصولات» اضافه شد.
- نام چند زیرشاخه نهایی به‌شکل کم‌رنگ زیر عنوان دکمه نمایش داده می‌شود.
- با انتخاب دکمه، منوی Dynamic چندستونه در دسکتاپ و مرحله‌ای در موبایل باز می‌شود.
- لینک‌های «پیشنهاد شگفت‌انگیز»، «پرفروش‌ها»، «پکیج‌های خودرویی» و «سرویس در محل» روبه‌روی آن قرار گرفتند.
- تعداد سطوح دسته‌بندی همچنان محدود و هاردکد نشده است.

## نصب و تست

ZIP را در ریشه پروژه Extract و فایل‌های هم‌نام را Replace کنید. SQL جدید لازم نیست.

```powershell
npm run typecheck
npm run build
.\agent-category.ps1
```

بعد از Build، فقط محتویات پوشه `dist` را روی `public_html` جایگزین کنید و `.htaccess` و فایل‌های احراز دامنه/اینماد را نگه دارید.
