# پچ Carrtell Mobile UX V4

این پچ مستقیماً بر اساس سورس کامل `project(2).zip` ساخته شده است.

## تغییرات
- Bottom Navigation موبایل پایدار شد و دیگر با فوکوس روی input ناپدید نمی‌شود.
- موقعیت منوی پایین به صورت fixed و با Safe Area آیفون تثبیت شد.
- Search اصلی از اولین حروف، محصول مرتبط را رتبه‌بندی و نمایش می‌دهد.
- نرمال‌سازی حروف فارسی/عربی برای جستجو اضافه شد (ی/ي و ک/ك و نیم‌فاصله).
- پیشنهاد دسته‌بندی و برند نیز بالای نتایج Live Search نمایش داده می‌شود.
- شماره موبایل در مرحله اطلاعات مشتری رزرو قابل تایپ شد.
- دکمه «تأیید شماره» اضافه شد؛ OTP با Supabase Auth ارسال و بررسی می‌شود.
- بعد از ارسال OTP فیلد کد تأیید و دکمه «ثبت کد» نمایش داده می‌شود.
- بدون تأیید شماره، عبور از مرحله اطلاعات مشتری ممکن نیست.
- ورود اجباری جداگانه برای رزرو ایجاد نشده؛ تأیید شماره در همان فرم رزرو انجام می‌شود.
- دکمه «انصراف از رزرو» در تمام مراحل اضافه شد.
- ظاهر فرم رزرو در موبایل تیره و هماهنگ با Carrtell نگه داشته شد.
- پنجره انتخاب خودرو بالاتر از Bottom Nav قرار می‌گیرد تا تداخل نداشته باشد.

## فایل‌های جایگزین

- `src/components/Layout.tsx`
- `src/pages/BookPage.tsx`
- `src/index.css`

## SQL
این پچ SQL جدید ندارد. Migration مربوط به Guest Service در سورس مبنا از قبل موجود بود.

## OTP و Secretها
هیچ Secret جدیدی وارد Frontend نشده است. کد از `supabase.auth.signInWithOtp` استفاده می‌کند و سورس فعلی پروژه از قبل Edge Function `supabase/functions/send-sms-hook` برای Kavenegar دارد. `KAVENEGAR_API_KEY` باید فقط در Secrets سمت Supabase باقی بماند.

## نصب
1. از پوشه فعلی پروژه یک Backup بگیر.
2. محتوای پوشه `project` داخل ZIP را روی ریشه پروژه خودت Extract کن و Replace را تأیید کن.
3. در PowerShell داخل پروژه اجرا کن:

```powershell
npm run typecheck
npm run build
```

4. پوشه جدید `dist` را روی هاست جایگزین کن.
5. روی آیفون/موبایل مرورگر را کامل ببند و دوباره باز کن یا Cache سایت را پاک کن.

## تست بعد از نصب
1. صفحه خانه: Bottom Nav باید از اولین بارگذاری نمایش داده شود و وسط صفحه ظاهر نشود.
2. روی Search بزن و فقط «ف» یا «فیل» تایپ کن؛ نتایج مرتبط باید بلافاصله باز شوند.
3. «فیلتر پراید» را تایپ کن؛ محصولاتی که واژه‌های فیلتر و پراید را دارند باید بالاتر نمایش داده شوند.
4. وارد رزرو سرویس شو؛ در همه مراحل «انصراف از رزرو» باید دیده شود.
5. مرحله اطلاعات مشتری: شماره 11 رقمی 09... وارد کن و «تأیید شماره» را بزن.
6. باید OTP پیامکی ارسال شود؛ کد را وارد و «ثبت کد» را بزن.
7. پس از تأیید، پیام سبز «شماره موبایل با موفقیت تأیید شد» نمایش داده شود.
8. رزرو را تا مرحله نهایی ادامه بده.
9. پنجره انتخاب خودرو را باز کن و بررسی کن لیست/پنجره زیر Bottom Nav نرود.

## نتیجه بررسی فنی
`npm run typecheck` روی سورس پچ PASS شد. Build در محیط تحویل به دلیل وجود `node_modules` ویندوزی داخل ZIP مبنا و نبود optional binary لینوکسی Rollup قابل اجرا نبود؛ این خطا مربوط به سورس TypeScript پچ نیست. Build را روی همان محیط Windows پروژه اجرا کن.
