# Carrtell V3.4.4 — اتصال پویا به صفحه صنعتی

این پچ دو مسیر خواسته‌شده را به `/industrial` متصل می‌کند:

- کارت تبلیغاتی «ویژه صنایع و ناوگان سنگین»
- کارت دسته «روغن‌های سنگین و صنعتی»

اتصال کارت دسته در کد به نام یا Slug ثابت وابسته نیست. در پنل مدیریت دسته‌بندی‌ها، فیلد جدید «صفحه مقصد اختصاصی» اضافه شده است. مقدار `/industrial` باعث می‌شود همان کارت، حتی اگر زیرشاخه داشته باشد، مستقیم وارد صفحه صنعتی شود. خالی‌بودن این فیلد رفتار عادی دسته‌بندی و فروشگاه را حفظ می‌کند.

## ترتیب نصب

1. ZIP را در ریشه پروژه Extract و Replace کنید.
2. فایل `supabase/manual/CARRTELL_INDUSTRIAL_DESTINATION_SAFE.sql` را در Supabase SQL Editor اجرا کنید.
3. سپس دستورهای زیر را اجرا کنید:

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"
npm run typecheck
npm run build
.\agent-category.ps1
```

به‌دلیل تداخل شماره Migrationهای قدیمی پروژه، برای این تحویل `npx supabase db push` اجرا نکنید؛ SQL امن بالا را مستقیماً در SQL Editor اجرا کنید.

## بررسی دستی

1. صفحه خانه را در دسکتاپ و موبایل باز کنید.
2. «دسته‌بندی محصولات» را باز کنید.
3. روی کارت «روغن‌های سنگین و صنعتی» بزنید؛ آدرس باید `/industrial` شود.
4. دوباره منو را باز کنید و روی «ویژه صنایع و ناوگان سنگین» بزنید؛ آدرس باید `/industrial` شود.
5. در پنل ادمین، دسته‌بندی‌ها، دسته موردنظر را ویرایش کنید و مقدار «صفحه مقصد اختصاصی» را ببینید.
6. برای هر دسته جدید می‌توانید مسیر دیگری وارد کنید؛ اگر فیلد را خالی کنید، همان دسته طبق روال عادی فروشگاه باز می‌شود.
