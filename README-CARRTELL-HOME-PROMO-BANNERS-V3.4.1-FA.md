# پچ اصلاحی Carrtell V3.4.1

این نسخه محل چهار بنر را مطابق تصویر مرجع اصلاح می‌کند.

## نتیجه نهایی

- چهار بنر از داخل Mega Menu دسته‌بندی حذف شده‌اند.
- چهار باکس قدیمی «ارسال سریع، ضمانت اصالت، بسته‌بندی امن و پشتیبانی» حذف شده‌اند.
- چهار بنر لینک‌دار جای همان چهار باکس در کنار بنر اصلی صفحه خانه قرار گرفته‌اند.
- عنوان، تصویر، لینک، ترتیب و فعال/غیرفعال‌بودن بنرها از پنل ادمین قابل مدیریت است.
- کارت‌های دسته‌بندی صفحه خانه و دسته‌های مادر منوی آبشاری، تصویر آپلودشده در پنل دسته‌ها را نمایش می‌دهند.
- منوی پایین موبایل و فرایند رزرو سرویس تغییر نکرده‌اند.

## نصب

فایل ZIP را داخل ریشه پروژه Extract و Replace کن. اگر دستی Extract کرده‌ای، `Expand-Archive` اجرا نکن.

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"

npx supabase db push

npm run typecheck
npm run build
.\agent-category.ps1
```

## مشاهده نتیجه

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

آدرس:

```text
http://127.0.0.1:4173/
```

## مسیرهای پنل مدیریت

مدیریت چهار بنر صفحه خانه:

```text
پنل ادمین ← محتوای صفحه اصلی ← چهار بنر کنار بنر اصلی صفحه خانه
```

مدیریت تصویر کارت دسته‌بندی:

```text
پنل ادمین ← دسته‌بندی‌ها ← ویرایش دسته ← تصویر یا آیکون دسته‌بندی
```

## انتشار روی هاست

پس از Build فقط خروجی جدید `dist` را منتقل کن. فایل‌های اختصاصی هاست مانند `.htaccess`، `cgi-bin` و فایل تأیید اینماد حذف نشوند.
