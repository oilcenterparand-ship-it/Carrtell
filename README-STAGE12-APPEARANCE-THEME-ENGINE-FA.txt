پچ مرحله ۱۲ Carrtell — بازسازی موتور تم و ظاهر سایت

تغییرات اصلی:
- انتخاب هر تم بلافاصله ذخیره و روی کل سایت اعمال می‌شود.
- تم ذخیره‌شده پیش از Render اولیه بارگذاری می‌شود تا با Refresh از بین نرود.
- شش تم Carrtell Classic، Premium Dark، Digikala Style، Auto Sport، Luxury و Eco Green بازطراحی شدند.
- برای هر تم رنگ‌های مستقل زمینه، کارت، متن اصلی، متن کم‌رنگ، حاشیه، فیلد، هدر، دکمه، موفقیت، هشدار و خطا تعریف شد.
- کلاس‌های قدیمی Tailwind در صفحات سایت، پروفایل، Checkout و پنل مدیریت به متغیرهای تم متصل شدند.
- قانون جلوگیری از همرنگ شدن متن و زمینه برای تم‌های روشن و تیره اضافه شد.
- فونت انتخابی در کل برنامه و پنل مدیریت اعمال می‌شود.
- صفحه Appearance دارای ذخیره خودکار و پیش‌نمایش واقعی کنتراست شد.
- import تکراری CSS حذف شد.

تست انجام‌شده:
- npm run build: موفق

نکات موجود از قبل در پروژه و نامرتبط با این پچ:
- چند فایل فونت در public/fonts موجود نیستند و Vite هشدار می‌دهد.
- TypeScript چند خطای قدیمی در recommendationsApi، driverJobsApi، SMS و importهای بلااستفاده گزارش می‌دهد.
- حجم Bundle اصلی حدود 992KB است و در آینده بهتر است Code Splitting انجام شود.
