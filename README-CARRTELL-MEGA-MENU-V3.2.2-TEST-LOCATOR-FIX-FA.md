# اصلاح انتخاب‌گر تست منوی دسته‌بندی

نسخه: ۳.۲.۲

در نسخه قبل، تست عنوان منوی صفحه اصلی با متن عمومی اجرا می‌شد. چون همان متن در عنوان ستون اول نیز وجود داشت، ابزار تست دو عنصر پیدا می‌کرد و پیش از بررسی ابعاد متوقف می‌شد.

این اصلاح انتخاب‌گر را فقط به عنوان اصلی سربرگ دسکتاپ محدود می‌کند.

هیچ کد رابط کاربری، دیتابیس یا اطلاعات محرمانه‌ای در این اصلاح تغییر نمی‌کند.
