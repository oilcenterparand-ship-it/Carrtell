# Carrtell V3.6.5.0 — تخصیص خودکار مأموریت

## قابلیت‌ها

- دکمه «برای فردا آمادگی دارم» در پنل سرویس‌کار
- ثبت ساعت شروع و پایان آزاد فردا
- تخصیص فقط برای رزروهای پرداخت‌شده
- جلوگیری از تخصیص دو مأموریت در یک ساعت به یک سرویس‌کار
- سقف روزانه ۵ مأموریت
- اولویت تکمیل ۵ مأموریت سرویس‌کار اول، سپس سرویس‌کار بعدی
- تخصیص رزروهای پرداخت‌شده‌ای که پیش از اعلام آمادگی منتظر مانده‌اند
- حفظ امکان اصلاح دستی تخصیص توسط مدیر

## نصب

محتویات ZIP را در ریشه پروژه Extract و Replace کنید.

### اجرای SQL الزامی
