# Carrtell fonts

فایل‌های فونت را با فرمت `.woff2` داخل همین پوشه قرار بده.

نام‌های آماده‌ای که پنل می‌شناسد:

- `Vazirmatn.woff2` → Carrtell Vazirmatn
- `Yekan.woff2` → Carrtell Yekan
- `Shabnam.woff2` → Carrtell Shabnam
- `Dana.woff2` → Carrtell Dana
- `IranSans.woff2` → Carrtell IranSans

بعد از کپی فونت، از پنل مدیریت → تنظیمات، فونت هر بخش را انتخاب کن.
