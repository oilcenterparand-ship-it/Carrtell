# پچ Carrtell V3.4.0

این پچ منوی دسته‌بندی را با حفظ ساختار داینامیک فعلی تکمیل می‌کند.

## تغییرات

- نمایش تصویر یا آیکون هر دسته در جایگاه مستقل داخل کارت دسته‌بندی.
- نوار دسترسی صفحه اصلی با سه میانبر «پیشنهاد شگفت‌انگیز»، «پرفروش‌ها» و «پکیج‌های خودرویی».
- دکمه درخشان «رزرو سرویس» بدون تغییر منوی پایین موبایل یا فرایند رزرو.
- چهار بنر تصویری و لینک‌دار در فضای روبه‌روی تبلیغ اصلی Mega Menu.
- مدیریت کامل چهار بنر از پنل ادمین: عنوان، توضیح، نشان، تصویر، لینک، ترتیب، فعال/غیرفعال، افزودن، ویرایش و حذف.
- چهار تصویر آزمایشی سبک WebP در مسیر `public/images/mega-menu`.
- تست Regression برای جلوگیری از حذف قابلیت‌ها و کنترل داینامیک پنل.

## نصب وقتی ZIP را قبلاً دستی Extract کرده‌ای

اگر محتویات ZIP را در ریشه پروژه Extract و Replace کرده‌ای، دستور `Expand-Archive` را اجرا نکن.

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"

npx supabase db push

npm run typecheck
npm run build
.\agent-category.ps1
```

هنگام اجرای Agent:

- نام کاربری واقعی ادمین را در پنجره PowerShell وارد کن.
- رمز را مخفی وارد کن؛ رمز در چت یا فایل ذخیره نمی‌شود.
- Agent بعد از پایان یا شکست، متغیرهای Credential را پاک می‌کند.

## کنترل دستی دسکتاپ

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

سپس `http://127.0.0.1:4173/` را باز کن و بررسی کن:

1. با رفتن موس روی «دسته‌بندی محصولات»، منو خودکار باز شود.
2. حرکت موس از دسته مادر به ستون بعد باعث بسته‌شدن یا ناپدیدشدن ستون نشود.
3. تصویر دسته در کادر کوچک خود نمایش داده شود.
4. چهار بنر روبه‌روی تبلیغ اصلی کامل دیده و قابل کلیک باشند.
5. سه میانبر بالایی و دکمه «رزرو سرویس» درست کار کنند.

## کنترل دستی موبایل

1. دسته‌ها مرحله‌به‌مرحله باز شوند و بازگشت کار کند.
2. چهار بنر کوچک در ابتدای منوی موبایل دیده شوند.
3. منوی پایین موبایل، دکمه رزرو و صفحه رزرو بدون تغییر باقی مانده باشند.

## پنل مدیریت

- تصویر دسته: `پنل ادمین ← دسته‌بندی‌ها ← تصویر یا آیکون دسته‌بندی`
- چهار بنر: `پنل ادمین ← محتوای صفحه اصلی ← چهار بنر کوچک منوی دسته‌بندی`

## انتشار هاست

پس از Build فقط خروجی جدید را جایگزین کن:

- `dist/index.html`
- `dist/assets`
- فایل‌های تصویری جدید از `public/images/mega-menu` که در Build داخل `dist/images/mega-menu` قرار می‌گیرند.

فایل‌های `.htaccess`، پوشه `cgi-bin`، فایل تأیید اینماد و فایل‌های اختصاصی هاست را حذف نکن.
