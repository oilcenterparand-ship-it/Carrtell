مرحله ۶ Carrtell

- رنگ کانتینر اصلی هدر با مقدار مستقیم قرمز تنظیم شد تا توسط تم یا کلاس‌های دیگر override نشود.
- نوار دسته‌بندی زیر هدر نیز قرمز تیره شد.
- هنگام خروج از حساب، خودروی انتخابی و فیلترهای موقت فروشگاه پاک می‌شوند.
- متن جستجو پاک می‌شود و کاربر بدون query string به صفحه اصلی بازمی‌گردد.
