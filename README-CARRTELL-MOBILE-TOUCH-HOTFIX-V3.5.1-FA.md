# هات‌فیکس Carrtell V3.5.1

ارتفاع قابل لمس دکمه انتخاب خودرو در صفحه فروشگاه موبایل از ۳۹ به ۴۰ پیکسل اصلاح شد. تست تغییر یا ضعیف نشده است.

## نصب و تست

فایل ZIP را در ریشه پروژه Extract و Replace کنید و سپس اجرا کنید:

```powershell
npm run typecheck
npm run build
.\agent.ps1 BOOKING
```

این هات‌فیکس SQL و تغییر دیتابیس ندارد.
