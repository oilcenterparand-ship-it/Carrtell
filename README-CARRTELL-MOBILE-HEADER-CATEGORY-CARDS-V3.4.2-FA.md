# پچ Carrtell V3.4.2

## تغییرات موبایل

- کوچک‌تر و جذاب‌تر شدن باکس انتخاب خودرو داخل منوی هدر.
- کوچک‌تر و برجسته‌تر شدن انتخاب خودرو بالای فروشگاه.
- تبدیل کارت‌های دسته مادر به ساختار تصویر در بالا و عنوان در پایین.
- نمایش داینامیک تصویر دسته به‌جای ایموجی، در صورت ثبت تصویر از پنل مدیریت.
- کوچک‌تر شدن فونت عنوان‌ها و زیرشاخه‌های دسته‌بندی.
- کوچک‌تر شدن نوار دسته‌بندی صفحه خانه.
- فعال‌شدن اسکرول افقی لمسی برای مشاهده پیشنهاد شگفت‌انگیز، پرفروش‌ها، پکیج‌ها و رزرو سرویس.
- منوی پایین موبایل و مراحل رزرو تغییر نکرده‌اند.

## نصب

ZIP را داخل ریشه پروژه Extract و Replace کن. اگر دستی Extract کرده‌ای، `Expand-Archive` اجرا نکن.

```powershell
cd "D:\carrtell\Carrtell-v0.2-current\project"

npm run typecheck
npm run build
.\agent-category.ps1
```

این پچ Migration جدید ندارد. اگر Migrationهای پچ V3.4.1 را هنوز اجرا نکرده‌ای، یک‌بار این دستور را نیز اجرا کن:

```powershell
npx supabase db push
```

## بارگذاری تصویر دسته

```text
پنل ادمین ← دسته‌بندی‌ها ← ویرایش دسته ← تصویر داخل کارت دسته‌بندی
```

برای کارت روغن دیزل می‌توانی تصویر گالن ۲۰ لیتری را در همین قسمت آپلود کنی.

## کنترل دستی موبایل

1. منوی همبرگری را باز کن و اندازه و ظاهر انتخاب خودرو را بررسی کن.
2. منوی دسته‌بندی را باز کن؛ تصویر دسته باید داخل مربع و عنوان زیر آن باشد.
3. نوار دسته‌بندی صفحه خانه را با انگشت به چپ و راست بکش.
4. گزینه‌های پیشنهاد شگفت‌انگیز، پرفروش‌ها، پکیج‌ها و رزرو سرویس باید قابل مشاهده باشند.
5. منوی پایین موبایل و دکمه رزرو باید بدون تغییر کار کنند.
