# Carrtell Industrial Mega Menu V3

## قابلیت‌های تحویلی

- طراحی شیشه‌ای تیره و طلایی مطابق طرح شماره ۳.
- دسته‌بندی چندستونه با عمق نامحدود از داده‌های Dynamic فعلی.
- آیکون هر دسته مستقیماً از پنل دسته‌بندی خوانده می‌شود.
- تبلیغ مستقل دسکتاپ و موبایل داخل Mega Menu.
- مدیریت عنوان، توضیح، نشان، تصویر، متن دکمه، لینک و وضعیت تبلیغ از مسیر «پنل مدیریت ← صفحه اصلی».
- تصویر تبلیغ با سیستم فعلی پروژه به WebP تبدیل و در Supabase Storage آپلود می‌شود.
- اگر تصویر وارد نشود، آیکون تبلیغاتی کامیون و روغن نمایش داده می‌شود.

## نصب

1. ZIP را در ریشه پروژه Extract و فایل‌های هم‌نام را Replace کنید.
2. فایل زیر را یک‌بار در Supabase SQL Editor اجرا کنید:

`supabase/migrations/202608230002_mega_menu_promotion.sql`

3. سپس اجرا کنید:

```powershell
.\INSTALL-CARRTELL-MEGA-MENU-V3.ps1
.\agent-category.ps1
```

## تست دستی ادمین

به `/admin/home-content` بروید، بخش «تبلیغ داخل منوی دسته‌بندی» را ویرایش و ذخیره کنید؛ سپس فروشگاه را Refresh کنید.

## تست دستی مشتری

در دسکتاپ و موبایل منوی دسته‌بندی را باز کنید، شاخه‌ها را تا محصول ادامه دهید و لینک کارت تبلیغاتی را بررسی کنید.
