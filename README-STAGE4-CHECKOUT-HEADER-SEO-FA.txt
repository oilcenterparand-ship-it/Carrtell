مرحله ۴ Carrtell

تغییرات:
- پیام سبز «ورود تایید شده» فقط در مرحله اول سبد خرید نمایش داده می‌شود.
- پیام قرمز عمومی فقط در مرحله آدرس نمایش داده می‌شود.
- خودروی انتخاب‌شده فقط در مرحله اول سبد خرید نمایش داده می‌شود.
- فیلد شهر حذف شد و استان + شهرستان باقی ماند.
- نقشه انتخاب موقعیت دقیق زیر آدرس اضافه شد.
- ذخیره اختیاری آدرس با نام دلخواه اضافه شد.
- آدرس‌های ذخیره‌شده در خریدهای بعدی قابل انتخاب هستند.
- آیکون ورود هدر بعد از ورود به «سلام + نام کاربر» تبدیل می‌شود.
- دکمه خروج دارای راهنمای Hover است.
- دکمه‌های اصلی هدر راهنمای Hover دارند.
- کارت محصولات دارای title و alt توصیفی شده‌اند.
- فوتر کم‌ارتفاع‌تر و فشرده‌تر شد.

تست‌های پیشنهادی:
۱) سبد خرید: مرحله اول، اطلاعات، آدرس و پرداخت را پشت سر هم باز کنید.
۲) در آدرس، موقعیت را روی نقشه انتخاب کنید.
۳) گزینه ذخیره آدرس را فعال و نام «خانه» وارد کنید.
۴) به مرحله بعد بروید و سپس بازگردید؛ آدرس ذخیره‌شده باید قابل انتخاب باشد.
۵) پس از ورود، در هدر باید «سلام + نام» دیده شود.

وضعیت فنی:
- npm run build موفق است.
- خطاهای TypeScript قدیمی پروژه در بخش‌های ادمین، SMS، پیشنهاد هوشمند و راننده همچنان وجود دارند و مربوط به این مرحله نیستند.
- نقشه فعلی با انتخاب موقعیت و موقعیت فعلی کار می‌کند. برای نمایش رسمی کاشی‌های نشان، API Key نشان باید در تنظیمات پروژه ثبت و SDK نشان متصل شود.
