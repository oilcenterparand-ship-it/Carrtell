# اصلاح پنل دسته‌بندی Carrtell V2.1

این پچ ابهام فرم دسته‌بندی را برطرف می‌کند.

- دکمه مستقل «دسته اصلی جدید»
- دکمه مستقل «زیرشاخه جدید»
- انتخاب اجباری مسیر والد برای زیرشاخه
- عنوان ثابت و توضیح برای تمام فیلدها
- دکمه سبز «+ زیرشاخه» کنار هر شاخه موجود
- نمایش مسیر کامل شاخه‌ها
- امکان ساخت نامحدود سطح بدون تغییر کد و بدون نیاز به توسعه‌دهنده

## نصب
ZIP را روی پچ V2 در ریشه پروژه استخراج و Replace کن.

```powershell
npm run typecheck
npm run build
.\agent-category.ps1
```

SQL جدید لازم نیست.
