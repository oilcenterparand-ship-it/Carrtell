# Carrtell RC1-06A — اصلاح مرحله اول موبایل

این پچ فقط رابط موبایل را اصلاح می‌کند و SQL ندارد.

## تغییرات
- حذف نوار ناوبری قدیمی و تکراری داخل صفحه فروشگاه
- نگه‌داشتن فقط MobileBottomNav سراسری
- جلوگیری از هم‌پوشانی هدر با انتخاب خودرو و محتوای صفحه
- جلوگیری از شناور شدن دسته‌بندی‌ها وسط صفحه هنگام اسکرول
- کوتاه و افقی شدن کارت‌های تبلیغاتی
- کاهش ارتفاع کارت‌های انتخاب ساعت رزرو و اصلاح رنگ انتخاب/hover
- جمع‌وجور شدن فاصله‌ها و عنوان‌ها در موبایل
- ساده‌تر شدن منوی موبایل و غیرفعال شدن Mega Menu دسکتاپ در موبایل

## نصب
محتویات ZIP را در ریشه پروژه Replace کنید:

D:\carrtell\Carrtell-v0.2-current\project

سپس:

npm run typecheck
npm run build

محتویات dist جدید را در public_html جایگزین کنید.

## تست
- صفحه اصلی روی موبایل
- /shop و /shop/all-products
- /book
- باز و بسته شدن منوی همبرگری
- نوار پایین: خانه، فروشگاه، سرویس، سفارش‌ها، حساب

TypeScript بدون خطا بررسی شده است.
Build در محیط تولید پچ به علت مجوز فایل اجرایی Vite اجرا نشد؛ خطای TypeScript وجود ندارد.
