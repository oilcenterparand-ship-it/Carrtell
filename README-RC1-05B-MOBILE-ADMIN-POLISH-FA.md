# Carrtell RC1-05B — رفع باگ موبایل و تکمیل پنل

## نصب
محتویات ZIP را در ریشه پروژه Replace کنید.

سپس فایل زیر را در Supabase SQL Editor اجرا کنید:

`supabase/migrations/202607240010_mobile_admin_inventory_polish.sql`

بعد:

```powershell
npm run typecheck
npm run build
```

محتویات پوشه `dist` جدید را در `public_html` جایگزین کنید.

## موارد اصلی
- جمع شدن فیلترهای فروشگاه در موبایل و استفاده از پنل فیلتر
- کارت‌های تبلیغاتی افقی، باریک و کم‌ارتفاع
- رفع هم‌پوشانی هدر، دسته‌بندی و نوار پایین موبایل
- جمع‌وجور شدن صفحه همه محصولات و امکان حذف فیلتر خودرو
- بهینه شدن کارت‌های تاریخ و ساعت رزرو و رفع سفید شدن متن
- خوانایی داشبورد مدیریت در تم‌های مختلف
- برند محصول داینامیک از برندهای ذخیره‌شده
- ورودی قیمت با جداکننده هزارگان و واحد تومان
- تعریف انبار و انتخاب انبار محصول
- انتخاب انبار ارسال سفارش بعد از پرداخت/تأیید
- جایگزینی API با نوع پایه روغن داینامیک
- اصلاح متن سلام کاربر

## نکته
Build در محیط تولیدکننده پچ به علت Permission فایل اجرایی Vite اجرا نشد، ولی `npm run typecheck` بدون خطا انجام شد.
