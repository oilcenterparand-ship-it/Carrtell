# اصلاح ظاهری منوی دسته‌بندی کارتل

نسخه: ۳.۲.۱

این پچ فقط برای اصلاح خروجی نامناسب نسخه ۳.۲.۰ ساخته شده است.

## اصلاحات

- منو دقیقاً زیر نوار دسته‌بندی باز می‌شود.
- ارتفاع منو براساس فضای واقعی صفحه محاسبه می‌شود و پایین صفحه قطع نمی‌شود.
- سربرگ دسکتاپ همیشه عنوان «دسته‌بندی محصولات» را نشان می‌دهد.
- مسیر فعال به‌صورت کوچک داخل سربرگ نمایش داده می‌شود.
- کارت تبلیغاتی دیگر جمع یا بریده نمی‌شود.
- عرض کارت تبلیغاتی و ستون‌ها به نسبت تصویر مرجع نزدیک شده است.
- تاری پس‌زمینه حذف شده و سایت از پشت منو دیده می‌شود.
- اندازه عنوان‌ها، شاخه‌ها، فاصله‌ها و قاب طلایی اصلاح شده است.

## نصب

فایل زیپ را داخل ریشه پروژه استخراج و جایگزین کن.

برای این اصلاح، اجرای فایل دیتابیس جدید لازم نیست.
