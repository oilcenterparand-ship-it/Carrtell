# اصلاح حرکت موس و ظاهر نوار دسته‌بندی — نسخه ۳.۳.۲

این پچ بعد از نسخه ۳.۳.۱ نصب می‌شود.

## اصلاح باگ حرکت موس

- تغییر شاخه با مکث هدفمند ۱۱۰ میلی‌ثانیه انجام می‌شود.
- با ورود موس به ستون بعدی، تغییر در انتظار لغو می‌شود.
- عبور موس از روی دسته نهایی، شاخه بازشده را نمی‌بندد.
- دسته‌های دارای زیرشاخه همچنان با نگه‌داشتن موس باز می‌شوند.
- کلیک و حرکت با صفحه‌کلید همچنان پشتیبانی می‌شوند.

## اصلاح اندازه و ظاهر

- آیکون دسته‌های مادر ۲۵ درصد دیگر کوچک‌تر شده است.
- ارتفاع نوار دسته‌بندی از ۳۴ به ۲۹ پیکسل کاهش یافته است.
- عنوان‌ها و آیکون‌های نوار کوچک‌تر شده‌اند.
- زمینه سرمه‌ای چندلایه، خط طلایی ظریف و حالت فعال اضافه شده است.
- هنگام قرارگرفتن موس روی دسته مادر، خط طلایی کوتاه و حرکت بسیار ملایم نمایش داده می‌شود.

## محدوده ایمن

منوی پایین موبایل، رزرو سرویس، ورود، سبد خرید، پرداخت و دیتابیس تغییر نکرده‌اند. اس‌کیوال یا تابع لبه جدید لازم نیست.
