# Carrtell V5.1 — ساده‌سازی رزرو + حذف حساب + اصلاح QA Driver

مبنای توسعه: `project(20260821-141451).zip`

## تغییرات رزرو موبایل
- مرحله ۵ خلوت شد: نام، موبایل و انتخاب موقعیت روی نقشه.
- فیلد آدرس تکراری و لیست کارت‌های آدرس از این مرحله حذف شد.
- آدرس تشخیص‌داده‌شده فقط یک‌بار زیر نقشه نمایش داده می‌شود.
- توضیحات سرویس‌کار از مرحله ۵ حذف و به مرحله آخر منتقل شد.
- مرحله ۶ به خلاصه ضروری تبدیل شد: خودرو، زمان، محل، تعداد انتخاب‌ها و مبلغ نهایی.
- تیترها و توضیحات طولانی و فاکتور ریزشده در این مرحله حذف شد.

## حذف حساب کاربری
در `حساب من > پروفایل` یک بخش «حذف حساب کاربری» اضافه شده است.
روند: درخواست حذف → OTP به شماره حساب → تأیید کد → حذف Backend.

عملیات Backend:
- حساب Auth حذف می‌شود.
- داده‌های شخصی قابل حذف پاک می‌شوند.
- سفارش‌ها/سوابق مالی حذف کورکورانه نمی‌شوند و اطلاعات هویتی آن‌ها ناشناس می‌شود.
- حساب‌های مدیر و سرویس‌کار از این مسیر قابل حذف نیستند.
- Service Role فقط در Edge Function استفاده می‌شود و هیچ Secret وارد Frontend نشده است.

## اصلاح خطای پچ قبلی Driver PWA
خطای Persona قبلی ناشی از انتظار QA برای متن `Carrtell Driver` روی صفحه Job بود، در حالی که کارت نصب داخل تب «حساب من» قرار دارد.
تست اصلاح شد تا ابتدا هویت Manifest/Title را روی Driver بررسی کند و سپس داخل تب «حساب من» کارت نصب را تست کند.

## نصب
ZIP را در ریشه پروژه Extract/Replace کنید.

### SQL
ندارد.

### Deploy اجباری
```powershell
npx supabase functions deploy customer-account-delete --no-verify-jwt
```

### تست
```powershell
npm run typecheck
npm run build

$env:CARRTELL_ADMIN_USERNAME="admin"
$env:CARRTELL_ADMIN_PASSWORD="12345678"
$env:CARRTELL_TECH_USERNAME="service"
$env:CARRTELL_TECH_PASSWORD="12345678"

.\agent.ps1 PERSONAS
```

بعد از PASS، پوشه `dist` جدید را روی `public_html` جایگزین کنید.

## تست دستی موبایل
1. `/book` تا مرحله ۵: آدرس نباید دوبار پرسیده شود و توضیحات در این مرحله نباشد.
2. مرحله ۶: فقط خلاصه ضروری + توضیحات اختیاری + مبلغ و دکمه پرداخت.
3. `/dashboard#profile`: بخش حذف حساب دیده شود؛ حذف واقعی را فقط با حساب تست انجام دهید.
4. `/driver`: Manifest مستقل Driver و کارت نصب در تب حساب من فعال باشد.
