مرحله ۱۷ Carrtell

- رنگ هدر، نوار دسته‌بندی، جستجو، دکمه‌ها و منوهای هدر به تم فعال متصل شد.
- وضعیت خودروی انتخاب‌شده با رنگ موفقیت همان تم مشخص می‌شود.
- توضیح کوتاه محصول به کارت محصولات اضافه شد.
- در صورت خالی بودن توضیح، متن جایگزین از مشخصات محصول ساخته می‌شود.
- توضیح در دو خط نمایش داده می‌شود و عنوان کامل با نگه‌داشتن موس قابل مشاهده است.
- Build نهایی موفق بود.
