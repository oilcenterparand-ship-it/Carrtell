# Carrtell Admin & Operations Redesign V4.8

این پچ بر اساس ZIP کامل `project(20260820-112230).zip` ساخته شده است.

## هدف Sprint
این Sprint لایه‌ی اصلی پنل مدیریت را بازطراحی می‌کند تا مدیر برای کارهای روزانه بین صفحات متعدد سرگردان نشود.

### تغییرات اصلی
- منوی قدیمی تخت به منوی گروه‌بندی‌شده و جمع‌شونده تبدیل شد.
- بخش‌های اصلی منو اکنون به ۸ گروه واضح تقسیم شده‌اند:
  1. کار امروز
  2. عملیات سرویس
  3. فروشگاه و کالا
  4. مشتریان
  5. بازاریابی و محتوا
  6. مالی و پرداخت
  7. تیم و دسترسی‌ها
  8. تنظیمات و سیستم
- داشبورد جدید به «مرکز کار روزانه» تبدیل شد.
- مسیر «عملیات سرویس» به صفحه اصلی کار روزانه سرویس در محل تبدیل شد.
- تخصیص سرویس‌کار ساده شد: انتخاب سرویس‌کار، خودرو اختیاری، یک دکمه «تخصیص و ارسال مأموریت».
- تنظیمات فنی مثل تغییر دستی Status و ترتیب صف داخل «تنظیمات پیشرفته» پنهان شدند.
- Routeهای مدیریتی که قبلاً خارج از `AdminLayout` بودند به Layout اصلی منتقل شدند تا Header/Sidebar در تمام پنل یکسان باشد.
- صفحات مالی، تأمین‌کنندگان، خرید، شعب، محتوا، پشتیبانی، گزارش‌ها و سلامت سیستم نیز از Shell یکپارچه مدیریت باز می‌شوند.
- Persona QA ادمین بررسی می‌کند گروه «کار امروز» و لینک «عملیات سرویس» بعد از ورود وجود داشته باشند.

## نصب
ZIP را در ریشه پروژه Extract و Replace کن:

`D:\carrtell\Carrtell-v0.2-current\project`

سپس در PowerShell:

```powershell
npm run typecheck
npm run build

$env:CARRTELL_ADMIN_USERNAME="admin"
$env:CARRTELL_ADMIN_PASSWORD="12345678"
$env:CARRTELL_TECH_USERNAME="service"
$env:CARRTELL_TECH_PASSWORD="12345678"

.\agent.ps1 PERSONAS
```

## تست دستی کوتاه پس از PASS شدن Agent
1. `/admin/dashboard` را باز کن؛ باید داشبورد جدید با «امروز در Carrtell چه کاری داری؟» دیده شود.
2. از منوی «کار امروز» وارد «عملیات سرویس» شو.
3. یک سفارش سرویس پرداخت‌شده را باز کن.
4. سرویس‌کار را انتخاب کن؛ خودرو اختیاری است.
5. «تخصیص و ارسال مأموریت» را بزن.
6. سفارش باید در پنل همان سرویس‌کار دیده شود.

## نکته مهم
این Sprint بازطراحی Shell مدیریتی و مسیر عملیات را انجام می‌دهد. CRM خودکار مرحله‌به‌مرحله (پیامک خودکار، SLA، Timeline خودکار، نظرسنجی خودکار) باید در Sprint بعدی روی دیتابیس Live و Triggerهای واقعی نهایی شود تا بدون حدس به ساختار موجود اضافه شود.
