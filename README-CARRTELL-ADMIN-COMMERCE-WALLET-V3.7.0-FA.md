# Carrtell V3.7.0 — پنل ادمین، کمپین، سفارش و کیف پول

## تغییرات

- راهنمای فیلدهای صفحات اصلی پنل و توضیح مستقیم زیر فیلدهای عملیاتی.
- آپلود و فشرده‌سازی WebP بنر کمپین.
- ورود تاریخ و ساعت شروع/پایان کمپین به‌صورت شمسی.
- عنوان و توضیح چندخطی خدمات، آیکون آپلودی فشرده، توضیح اجرت و زمان تقریبی.
- دسته‌بندی خودکار سفارش‌ها و نمایش جداگانه پرداخت‌شده‌ها.
- بازکردن جزئیات، کم/زیاد/حذف و افزودن قلم سفارش.
- برگشت اتمیک اختلاف سفارش پرداخت‌شده به کیف پول مشتری.
- تخصیص مستقیم سفارش به سرویس‌کار فعال.
- شارژ کیف پول از پروفایل، تاریخچه تراکنش و پرداخت ترکیبی کیف پول + درگاه.
- مسدودکردن تغییر مستقیم موجودی کیف پول از مرورگر.
