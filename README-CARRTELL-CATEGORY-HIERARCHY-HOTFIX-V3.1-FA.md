# Hotfix سلسله‌مراتب دسته‌بندی Carrtell V3.1

## موبایل

- دسته مادر: کارت بزرگ‌تر، عنوان درشت، رنگ و کادر طلایی.
- زیرشاخه: اندازه متوسط و رنگ سفید.
- دسته نهایی: کارت کوچک‌تر، رنگ خنثی و عبارت «دسته نهایی محصولات».
- عنوان مرحله، شماره سطح و مسیر انتخاب‌شده در بالای کادر نمایش داده می‌شود.

## دسکتاپ

- هنگام بازشدن، مسیر صنعتی به‌صورت خودکار انتخاب می‌شود تا ستون‌های بعدی خالی نمانند.
- ترتیب صحیح RTL: دسته مادر راست، زیرشاخه‌ها وسط، تبلیغ چپ.
- ارتفاع، عرض، حاشیه و فضای داخلی کادر اصلاح شده است.
- محتوای تبلیغ حتی بدون تصویر با آیکون پیش‌فرض نمایش داده می‌شود.

## نصب

ZIP را در ریشه پروژه Extract و فایل‌ها را Replace کنید. SQL جدید لازم نیست.

npm run typecheck
npm run build
